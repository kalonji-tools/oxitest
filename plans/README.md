## Findings considered and rejected (2026-07-13 None audit)

- "LogCapture `_old_level: int | None`" — `&mut` exception class per ADR-0005; None-as-sentinel is correct for install/uninstall lifecycle.
- "AsyncioSharedSession `_loop: ... | None`" — `&mut` exception; None = "closed" is valid lifecycle state.
- "SharedAsyncManager `_session: ... | None`" — lazy init is correct; session shouldn't be created until first async fixture.
- "`_coverage` module-level optional import" — standard Python optional dependency pattern.
- "Plugin CLI extension `getattr(module, ..., None)`" — standard duck-typing plugin discovery; requiring the attribute would break the API.
- "`_fixture_context` ContextVar default None" — None means "outside test execution"; a default root would hide misuse.
- "`_test_run_context` ContextVar default None" — same reasoning.
- "Frame inspection cascading None (`inspect.currentframe()`)" — can return None per spec; defensive checks correct.
- "Plugin debugger/coverage redundant None guards in `plugin_loader.py`" — required by ty 0.0.46 (can't narrow through list comprehension filters).
- "Rust `short` flag `chars().next()`" — valid conversion for `Option<String>` → `Option<char>`.
- "Rust `env` conditional in `discover_plugin_cli`" — plugin CLI detail, LOW impact.
- "Rust `default_timeout: Option<u64>`" — genuinely optional (no timeout valid).
- "Rust `ast_weight: Option<DurationMs>`" — genuinely optional (AST prescan conditional).
- "Rust `pool: Option<Vec<...>>`" — good API clarity with `unwrap_or_default()`.
- "Rust `#[serde(default)]` on FromPyObject structs" — confused mechanism (FromPyObject, not serde).
- "Rust short-flag type mismatch" — plugin CLI discovery detail.
- "`_has_shared_cache: bool | None`" — valid lazy cache tri-state (None = unknown).
- "Coverage `_cov: Any = None`" in CoveragePyProvider — `&mut` exception class.
- "`_coverage` module-level optional import in `worker.py`" — same as above, standard pattern.
